📖 Sobre o Projeto

Sistema desenvolvido em Python para a empresa de marketing TudoWeb, com o objetivo de realizar uma pesquisa de satisfação com seus clientes sobre o atendimento prestado.

O programa coleta nome, idade e opinião de cada entrevistado e, ao final, exibe a quantidade de respostas EXCELENTE e RUIM.

🎯 Objetivo

Coletar dados de 50 entrevistados;

Registrar a opinião de cada um (1-EXCELENTE, 2-BOM, 3-RUIM);

Contar quantas respostas foram EXCELENTE e quantas foram RUIM;

Exibir o resultado final ao término da pesquisa.

📋 Regras de Opinião

Código	Opinião

1	EXCELENTE

2	BOM

3	RUIM
